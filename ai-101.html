Chapter 1

AI 101

Shared language for the team. These ideas come before the tech stack, and before anyone builds the teaching app.

The one-minute story

AI is not new. The recent wave happened because several ideas finally worked well together: neural networks learned from large amounts of data, GPUs made the math fast enough, Transformers handled context efficiently, large language models became capable, and chat interfaces made them easy to use.

Each new system solved a practical limitation in the one before it.

rules neural networks Transformers LLMs GenAI / chat RAG agentic AI

The ideas, in the order they became necessary

1

Is AI new?

No. AI is a broad field that has existed since the 1950s. Earlier systems used rules, search, statistics, and expert knowledge. They could be useful, but they were often brittle: they struggled with messy language, new situations, and the amount of hand-written logic required.

Rules→Useful but brittle→Learn from data
2

What problem were researchers trying to solve with language?

People wanted computers to understand and produce natural language instead of requiring exact commands. Language is hard because meaning depends on surrounding words, word order, tone, and real-world context.

Human language→Ambiguity + context→Language models
3

What is a neural network?

A neural network is a set of connected mathematical layers. During training, it adjusts many numbers called weights so it gets better at recognizing patterns. A deep-learning model is a neural network with many layers. It does not think like a person. It learns useful mathematical patterns from examples.

Examples→Layers + weights→Learned patterns
4

What is a GPU, and why does it matter?

A GPU, or graphics processing unit, was built to draw images. It is also very good at doing many similar calculations in parallel. Neural networks use huge matrix calculations, so GPUs and other accelerators make training and inference much faster. A GPU is a speed enabler. It is not the model.

Matrix math→GPU: parallel work→Faster training and inference
5

What changed with “Attention Is All You Need”?

In 2017, that paper introduced the Transformer architecture. Its key idea, attention, lets a model weigh which parts of the input are most relevant to one another. A useful memory aid is “context is what you need.” The paper did not use that phrase. Its title is “Attention Is All You Need.”

The Transformer handled context well and could be trained more efficiently in parallel than many earlier recurrent approaches.

Tokens→Attention→Relevant context
6

What is a Transformer?

A Transformer is a neural-network architecture built around attention. It reads tokens and learns relationships between them. Transformers are the foundation for many language models. A Transformer by itself is not a chatbot or an agent.

Tokens→Transformer layers→Relationships + output
7

What is pretraining?

Pretraining is the first large learning stage. A language model sees a huge amount of text and repeatedly practices predicting the next token. It learns grammar, style, facts, and relationships stored as patterns in its weights. This creates a general-purpose base model.

Large text dataset→Predict next token→Base model
8

What is an LLM, and what does GPT mean?

An LLM is a large language model: a language model with a very large number of learned weights, trained on a large amount of text. The first GPT paper appeared in 2018. Later scaling, including GPT-3 in 2020, improved the model’s ability to follow patterns and perform many language tasks.

GPT stands for Generative Pre-trained Transformer:

  • Generative: it generates an output, usually one token at a time.
  • Pre-trained: it first learns general language patterns from large datasets.
  • Transformer: it uses the Transformer architecture.

GPT is one family of LLMs. Not every LLM is a GPT model.

Prompt→Tokens→GPT→Generated tokens
9

What is a token?

A token is a small piece of text that a model reads or produces. It can be a whole word, part of a word, punctuation, or a space-plus-word pattern, depending on the tokenizer. The model converts tokens into numbers, processes them, and predicts the next token.

Tokens are not exactly words. Token counts affect context limits, speed, and cost. A simple mental model is: text in, tokens, numbers, model, tokens out, text.

Text→Tokenizer→Token IDs→Model input
10

What is inference?

Inference is using a trained model. When someone sends a prompt, the model processes the input and generates an answer. Training changes the model’s weights. Inference uses those weights to produce an output. A chat answer is inference, not a fresh training run on every question.

For the team. The teaching app will call a model. That call is inference. It does not retrain the model for each person on the team.
Trained weights+Prompt→Inference→Answer
11

What is GenAI?

Generative AI, or GenAI, creates new output from a prompt or other input. An LLM generates text or code. Other generative systems generate images, audio, video, or structured data.

Prompt→Generative model→Text, code, image, or audio
12

Why did chat interfaces matter?

In 2022, ChatGPT made large language models easy for everyday people to use through conversation. It was not the first natural-language AI tool, and it was not the first way to use a GPT-style model. It made instruction-following, multi-turn conversation, and useful generation feel accessible in one product.

Person→Chat interface→Instruction-tuned model→Response
13

Why was RAG needed?

An LLM alone has two important limitations. Its training data has a cutoff, so it may not know recent information. It also does not automatically know private documents, policies, or current operational data.

The term RAG, retrieval-augmented generation, was formalized in a 2020 paper. RAG retrieves relevant information at question time and places it in the model’s context. The model then writes an answer using that context. RAG normally does not retrain the model.

question → search sources → select passages → prompt the model → grounded answer

For the team. If the teaching app must use the team’s own material, that is a retrieval decision. Updating the documents updates what the app can use, without training a new model.
Question→Retrieve sources→Context→Model answer
14

What are embeddings and a vector database?

An embedding is a list of numbers that represents the meaning or features of text. Texts with similar meaning tend to sit close together mathematically.

A vector database stores embeddings and searches for nearby vectors. In a RAG system, documents are split into passages, converted into embeddings, and indexed. A question is embedded too. The search finds relevant passages even when the wording differs.

The vector database is the search memory. The LLM is the language generator. Access control, redaction, and source quality still matter.

Documents + question→Embeddings→Vector search→Relevant passages
15

What is agentic AI?

A normal model call answers one prompt. An agentic system can take a goal, break it into steps, use tools, inspect results, remember relevant state, and continue until it reaches a stopping point.

An agent might search a knowledge base, call an API, check the result, and draft a response. Reliable systems need permissions, tool boundaries, logging, evaluation, and human approval for risky actions.

For the team. An agent is a bounded loop with tools. Approval for risky actions is a leadership decision, not a detail to add later.
Goal→Plan→Use tools→Observe↺
16

What is easy to miss?

  • Instruction tuning and alignment. After pretraining, models are further trained or configured to follow instructions and respect safety rules. That is a major reason a base model can become a usable assistant.
  • Grounding and evaluation. A fluent answer is not automatically a correct answer. Good systems test accuracy, cite sources where possible, protect private data, and define what the model must do when it is uncertain.
  • Multimodal AI. Modern systems also combine text with images, audio, video, code, and tools.
Model output→Grounding + evaluation→Trusted action

One picture to keep

LLM    = generates language
RAG    = supplies better context
Agent  = uses the model in a tool-using loop

An LLM predicts likely next tokens from the context it receives. RAG supplies better, more current context. An agent adds a loop so the model can use tools and complete multi-step work. All three still need good data, security, testing, and human judgment.
