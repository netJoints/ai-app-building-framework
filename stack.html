Chapter 2

The tech stack

This is the framework the teaching app is built on. The team needs to know which tool owns which job, and where credentials are allowed to live.

One app, three places people open it

The team builds one web app. Firebase Hosting serves it. Capacitor packages that same app for Android and iOS. Backend logic stays in Firebase Functions.

What each tool owns

Tool Need Role
GitHub Actions and secrets Code and automation Build, test, and deploy. API keys and credentials stay in GitHub Actions secrets, outside source code.
Firebase Hosting Hosting Serve the web app.
Firestore Document data Document database for flexible, document-shaped records.
Neon Relational data Postgres for structured, relational records.
Firebase Functions Backend logic Server-side logic. Model calls, Neon, and Stripe are reached from here.
Firebase Auth Users Sign-in, identity, and who is allowed to call the backend.
Stripe Payments Charges, subscriptions, and payment state.
Capacitor Mobile Package the same web app for Android and iOS.

How a request moves

Web or Capacitor app → Firebase Hosting → Firebase Auth → Firebase Functions → Firestore, Neon, Stripe

GitHub Actions sits beside that path. It builds the app, deploys Hosting and Functions, and supplies secrets at deploy time. The phone app and the hosted pages do not carry provider keys.

Where step 1 shows up in the app

1

Two kinds of data

Firestore holds document-shaped records. Neon holds relational rows. The shape of the record decides the store. Both are reached from Firebase Functions.

2

A model call is inference

When the app asks a model a question, that is inference. It uses a model that was already trained. The call belongs in Firebase Functions, with the provider key kept in GitHub Actions secrets.

3

RAG and agents are product choices on this stack

RAG retrieves the team’s own or current material and puts it in the prompt. It does not retrain the model. An agent is a loop in Functions: plan, use a tool such as the database or Stripe, observe, and continue. Permissions, logs, and human approval for risky actions stay part of the design.
